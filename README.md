# Vanshika Ludhani — Portfolio 

A sleek, animated, and performant developer portfolio showcasing my work in Backend Systems, AI/CV, and full-stack development.

## 🛠️ Tech Stack
* **Framework**: React 19 + TypeScript
* **Bundler**: Vite
* **Animations**: Framer Motion (Scroll animations, magnetic buttons, hover interactions)
* **Styling**: Vanilla CSS (CSS Variables, Flexbox/Grid, Responsive Design)
* **Icons**: Lucide React & Custom SVGs

## ✨ Features
* **Magnetic Buttons & Custom Cursor**: Smooth, physics-based interactions that follow the cursor.
* **Animated File Archive**: Project section built like a tech-themed file explorer with accordion drops.
* **Fully Responsive**: Adapts seamlessly from ultra-wide desktops to mobile screens.
* **Dark-Mode Native**: Sleek, high-contrast dark aesthetic with vibrant gradient accents.

## ⚙️ Running Locally
1. Clone the repository
```bash
git clone https://github.com/VanshikaLud04/portfolio.git
cd portfolio
```
2. Install dependencies
```bash
npm install
```
3. Start the dev server
```bash
npm run dev
```
